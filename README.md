# Yopandelreyz — Template Website Builder (No Login) + Pakasir QRIS (in-app) + Vercel Deploy (stub)

This is a **starter** monorepo (JS-only) for your idea:
- Templates: Bio Links, Portfolio, CV, Business Profile
- Free vs Premium tier (premium = paid)
- **Pakasir QRIS shown inside your UI** (create transaction via API, render QR in frontend)
- MongoDB (mongodb+srv) for storage
- Vercel deploy integration is scaffolded (service stub) — you can wire it after you set your Vercel token.

> All secrets are in **one file**: `apps/api/src/config/keys.js`

## Requirements
- Node.js 18+
- MongoDB Atlas connection string (mongodb+srv)
- Pakasir `projectSlug` + `apiKey`
- (Optional later) Cloudflare token + zone ID + base domain
- (Optional later) Vercel token

## Quick start (dev)
```bash
npm install
npm run dev
```

- Web: http://localhost:3000
- API: http://localhost:4000

## Configure keys (ONE FILE)
Edit:
`apps/api/src/config/keys.js`

## Pricing (single source of truth)
`packages/shared/pricing.js`

## Flow (MVP)
1) Open `/templates`, pick template.
2) Create site on `/create`
3) Choose tier: free or premium
4) If premium -> `/checkout` shows **QRIS QR** (generated by Pakasir API)
5) After paid -> you can handle webhook to trigger deploy (stub included)

## Notes
- Webhook verification is implemented in a safe pattern (webhook -> verify via transactiondetail -> mark paid).
- Deploy to Vercel is a stub in `apps/api/src/services/vercel.service.js` — connect it when ready.
